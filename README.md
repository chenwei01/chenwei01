# 小学课程资料商城

一个专为小学生1-6年级设计的课程资料销售网站，提供优质的教学资源和学习材料。

## 功能特色

### 🎯 核心功能
- **课程分类展示**: 按年级（1-6年级）分类展示课程
- **购物车系统**: 完整的购物车功能，支持添加、删除、结算
- **用户系统**: 用户注册、登录功能
- **管理后台**: 完整的后台管理系统，支持课程、订单、用户管理
- **响应式设计**: 支持手机、平板、电脑多端访问

### 📚 课程内容
每个年级包含以下类型的课程：
- **语文课程**: 拼音、识字、阅读、写作
- **数学课程**: 数字认知、运算、几何、思维训练
- **英语课程**: 字母、单词、语法、听说读写
- **综合课程**: 科学、美术、音乐、体育等

### 🛒 购物体验
- 直观的课程卡片展示
- 一键添加到购物车
- 实时购物车更新
- 简单的结算流程

### 📱 用户界面
- 现代化的设计风格
- 流畅的动画效果
- 友好的用户交互
- 清晰的信息展示

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **样式**: 响应式设计，CSS Grid/Flexbox
- **图标**: Font Awesome
- **服务器**: Python HTTP Server

## 响应式设计

网站采用响应式设计，在不同设备上都有良好的显示效果：

- **桌面端**: 完整功能展示，多列布局
- **平板端**: 适配中等屏幕，调整布局
- **手机端**: 单列布局，汉堡菜单，全屏购物车
